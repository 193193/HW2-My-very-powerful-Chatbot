# Gemini 2.5 智慧對話小工具

這是一個基於 Google Gemini 2.5 API 開發的輕量化網頁聊天介面。具備長期記憶與模型自動路由功能，無需複雜後端設定即可在瀏覽器直接執行。

---

## 核心功能

* **即時 AI 對話**：接入最新的 Gemini 2.5 Flash 模型，反應迅速且支援繁體中文。
* **自動模型路由**：系統根據輸入長度自動切換模型（簡單訊息使用 `2.5 Flash Lite`，複雜任務使用 `2.5 Flash`）。
* **多模態支援**：支援圖片分析功能，可直接上傳圖片並進行對話詢問。

* **持續對話記憶**：支援上下文關聯（Chat History），AI 會記得你之前說過的話。
* **長期記憶系統**：支援跨對話記憶與跨 session 紀錄，AI 會記得你過去提及的興趣與偏好。
* **MCP 日曆功能**：內建模擬日曆工具，可透過對話直接讀取或寫入每日任務紀錄。
* **錯誤重試機制**：針對 503 等 API 繁忙錯誤提供一鍵重試按鈕，確保對話不中斷。
* **Markdown 解析**：支援程式碼高亮、列表與表格顯示。

---

## 如何開始使用

1.  **取得 API Key**：
    前往 [Google AI Studio](https://aistudio.google.com/) 免費申請你的 Gemini API Key。

2.  **設定設定檔**：
    在專案目錄下建立一個 `config.js` 檔案，並填入你的 Key：
    ```javascript
    window.CONFIG = {
        API_KEY: '你的_API_KEY_貼在這裡'
    };
    ```

3.  **執行網頁**：
    直接雙擊開啟 `index.html`，或使用 VS Code 的 `Live Server` 套件運行即可開始聊天！

---

## 使用小撇步

* **快速發送**：輸入文字後直接按 `Enter` 鍵即可送出訊息。
* **純淨回答**：系統預設會要求 AI 直接提供重點，不會有過多的客套話。
* **新對話**：點擊「＋ 新對話」可清空目前畫面，但 AI 仍會保留之前的長期記憶。
* **清除記憶**：若需刪除所有對話紀錄與日曆任務，請點擊「🗑️ 清除所有記憶」。
* **日曆指令**：你可以直接用自然語言進行日曆操作，系統會自動執行 JSON 讀寫。
* **重試功能**：若遇到系統繁忙（503 錯誤），點擊訊息下方的紅色按鈕即可重新發送同一段文字。
